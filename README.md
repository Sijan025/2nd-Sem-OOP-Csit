## 🚀 How to Run the Code

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Sijan025/2nd-Sem-OOP-Csit.git
   cd 2nd-Sem-OOP-Csit
   ```
2. **Compile a C++ file:**

```bash
  g++ Chapter-01/filename.cpp -o program
```

3. **Run the executable:**
   - **Linux/macOS:** `./program`
   - **Windows:** `program.exe`
